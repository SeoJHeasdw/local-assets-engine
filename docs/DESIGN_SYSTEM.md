# Assets Studio 디자인 시스템

## 원칙

결과가 중심이다. 생성 시에는 의도와 만드는 순서를, 편집 시에는 에셋과 변경 결과를 보여 준다.
모델 이름·표면 재구성·UV·최대 메모리는 일상 제작에 필요한 선택이 아니다. 단계 기록은 지우지
않고 작업 기록 팝업과 환경 화면에서 보여 준다.

## 토큰과 컴포넌트

- `electron-app/renderer/tokens.css`: 공통 색상, 글자, 간격, 모서리, 높이, 동작 시간.
  어두운 중성 바탕 위에 앰버를 주 동작·선택·편집 위치에 사용한다. 성공·주의·오류 색은 상태에만 쓴다.
- `styles.css`: 앱 뼈대와 기존 공통 컴포넌트·프리비즈.
- `studio.css`: 생성 스튜디오, 공통 팝업, 편집 공간. 페이지 특화 값은 해당 클래스 아래에 둔다.
- `ui.js`: 공용 팝업, 상태 알림, 이미지 선택·가져오기. 사용자 입력과 오류는 텍스트로 삽입하거나 escape한다.

| 컴포넌트 | 용도 |
| --- | --- |
| `.primary` | 현재 화면을 진행하는 핵심 동작 하나. 생성 또는 새 버전 저장 |
| `.secondary` / `.ghost` | 가져오기·비교·기록·보조 동작 |
| `.studio-dialog` | 생성 설정·컨셉 선택·변환 시작·작업 기록·에셋 정보 |
| `.editor-dialog` | 큰 에셋 뷰포트 + 도구 패널 + 항상 보이는 저장 영역 |
| `.layer-row`, `.layer-props` | 편집 레이어 한 줄(보이기·이름·잠금·순서·삭제)과 고른 레이어의 속성 |
| `.editor-overlay` | 2D 미리보기 위 자르기 틀(`.crop-box`)·로고 상자(`.stamp-box`)와 손잡이 |
| `.compare-dialog` | 후보를 크게 나란히 보고 고르는 팝업 |
| `.edit-range`, `.field`, `.check-label` | 이름이 붙은 입력, 표시 값, 키보드 조절 |
| `.quality-note` | 사용자가 선택한 품질·다음 동작을 짧게 설명 |
| `toast()` | 완료·실패·다음 동작. 주 화면 흐름을 막지 않음 |

설정이나 정보를 보기 위해 팝업을 사용한다. 즐겨찾기·컬렉션·승인은 사람이 명시적으로 고를 때만 바뀐다.
편집 저장은 새 버전을 만들며 원본은 덮어쓰지 않는다. 불필요한 확인 창을 추가하지 않는다. 확인을 받는 것은
휴지통으로 보내기처럼 목록에서 결과가 사라지는 동작뿐이다.

창에는 제목 막대가 없다. 화면 맨 위 띠와 각 화면의 머리글(`.studio-head`, `.view-head`, `.pv-bar`, 사이드바)을
잡아 창을 옮긴다. 머리글 안의 단추·입력·칩·세그먼트는 끌기에서 빠져 그대로 눌린다. 모달이 열려 있으면 머리글
끌기를 끄고 맨 위 띠만 남긴다.

## 화면별 계약

- **만들기:** 3D 소품/2D 이미지 → 설명 또는 이미지 → 생성. 3D의 컨셉 확인/바로 완성은
  후보 수와 독립된 명시적 선택이다. 후보 수·시드는 설정 팝업, 형상 해상도·면 수는 고급 설정에 둔다.
  기본은 고품질 원본 하나다. 생성 버튼은 스크롤해도 접근 가능해야 한다.
  작성 중인 설명·스타일·설정·고른 이미지는 앱을 다시 열어도 남는다.
  2D는 게임 에셋/실사/애니·일러스트 카테고리 다음에 만들 종류를 고른다. 프리셋에 맞는 예시를 보여 주며,
  모델 선택은 생성 설정에 두고 카테고리별로 기억한다. 실사·애니는 배경 포함이 기본이다.
- **최근 작업:** 결과 썸네일과 간단한 상태. 대기 중이면 앞에 남은 작업 수와 기다린 시간, 끝나면 처리 시간과
  (5초 이상이면) 대기 시간을 따로 적는다. 후보가 2장 이상이면 `나란히 비교`로 크게 보고 고른다. 고른 후보는
  즐겨찾기와 메모(고른 이유)로 남는다. 창을 보고 있지 않을 때 작업이 끝나면 macOS 알림을 띄우고 누르면 결과를 연다.
  자세한 시간·메모리·로그는 `작업 기록`에서 본다.
  같은 조건의 성공 기록이 충분하면 완료까지의 대략적인 시간을 함께 적는다. 기록 부족·예상 초과는 숫자 대신 상태로 표시한다.
- **보관함:** 전체/즐겨찾기, 종류, 컬렉션, 태그 칩, 이름·태그·메모 검색. 카드의 ★로 바로 즐겨찾기한다.
  이미지·3D에는 승인·거절을 쓰지 않는다. 다음 동작(편집·3D 변환·프리비즈)이 승인을 요구하지 않아 표시만
  늘리기 때문이다. 승인·거절은 컷을 확정하는 프리비즈 검토에만 남긴다.
  카드 왼쪽 위 체크박스로 현재 목록을 다중 선택하고 컬렉션·태그를 일괄 정리한다. 필터 밖의 선택은 해제한다.
  휴지통 정리는 에셋 단위가 아니라 해당 작업 전체이며, 포함할 작업 목록과 참조 관계를 확인 창에 표시한다.
- **편집:** 레이어 목록이 중심이다. `색 바꾸기`(비슷한 색만/영역 전체 칠하기 × 에셋 전체/칠한 곳만), `로고`,
  `문구`를 여러 개 쌓고 보이기·잠금·순서·삭제를 한다. 색 레이어는 에셋 색, 로고·문구는 그 위에 쌓인다.
  브러시로 칠한 곳은 주황으로 표시하고, 3D에서는 표면 위 드래그가 칠하기·빈 곳 드래그가 회전이다.
  2D 로고는 상자를 끌어 옮기고 모서리로 크기, 위 손잡이로 회전하며 가운데에서 스냅한다. 3D 로고는 끌면 표면을
  따라 움직이고 Alt+휠로 크기, Shift+휠로 회전한다. 3D 로고는 기본으로 찍은 곳과 이어진 표면에만 붙는다.
  2D 구성 탭은 비율 칩과 자르기 틀, 여백·배경색, 출력 가로 크기를 다룬다. 이것은 표면 편집이며 조각·불리언·리깅
  도구로 표시하지 않는다. 원본 비교, 되돌리기(⌘Z)·다시 실행(⇧⌘Z), 단계를 골라 돌아가는 `작업 내역`을 제공한다.
- **저장 대기:** 다른 작업이 돌고 있으면 저장 영역에 대기 중임과 기다린 시간을 보여 주고 `저장 취소`를 둔다.
  창을 닫아도 순서가 오면 저장되고 알림으로 알린다. 3D 변환·프리비즈·내보내기는 저장이 끝난 새 버전으로 이어진다.
- **프리비즈:** 설명 입력이 기본 시작점이다. 예시는 설명을 채우는 보조 동작이고 사용자가 보강할 수 있다.
  적용한 배치·카메라와 지원하지 않는 내용을 보여 준 뒤 영상으로 확인한다. `previz-quick.css`가 간편 화면을 소유한다.
  렌즈·좌표·보조 패스는 상세 편집에 두고, 간편 화면에는 주인공·컷 길이·영상 검토를 남긴다. 두 화면은 같은 초안을 쓴다.
  준비 그림은 실제 카메라 미리보기로 표시하지 않는다. 예전 결과는 기록에서 명시적으로 열고 저장된 영상임을 알린다.
  설명을 바꿔도 자동으로 렌더하지 않는다. 장면 준비와 영상 만들기를 분리하고, 영상 만들기는 스크롤 밖에 고정한다.
- **버전:** 저장된 편집 설정과 기준 파일을 함께 보관한다. 재편집은 기준 파일에 설정을 재적용하여
  색이나 로고가 누적되지 않는다. `버전 이력`은 원본부터 편집·재구성·3D 변환 갈래를 나무로 보여 주고
  어느 버전이든 열어 새 갈래로 편집한다.
- **임시 편집:** IndexedDB에 보관하고 닫았다 다시 열거나 앱을 다시 시작해도 복원한다.
  파일로 저장된 결과와 즐겨찾기 상태를 혼동하지 않는다.
- **환경 · 보관 용량:** 결과물·다시 만들기용 원본·사본·미리보기·중간 파일·기타·기록의 비율 막대와 큰 작업 목록.
  1MB 이상의 중간 파일만 정리 단추를 보이고, 휴지통으로 보내기 전에 무엇이 남는지 알린다.

## 접근성과 크기

키보드 포커스 링, 레이블, 탭 선택 상태, 원본 비교 눌림 상태, 라이브 상태 문구를 유지한다.
팝업은 native `dialog`로 포커스를 가두고 Escape로 닫는다. 글 입력 중의 기본 Undo를 가로채지 않는다.
색만으로 상태를 전달하지 않는다. 동작 감소 설정을 존중한다.

1280×720에서 생성·저장 버튼이 보이는지, 좁은 창에서 입력과 뷰포트가 겹치지 않는지 확인한다.
프리비즈의 배치·컷 편집 기능과 공통 토큰을 함께 사용하되 별도 제작 흐름을 유지한다.
